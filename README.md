# Group Project 1: Stock Visualization and Business Analysis

**Members:** Hardy、Justin、Flores
**Tickers:** AMZN, SBUX, CMG (three consumer-focused companies)
**Date range:** 2024-07-01 to 2025-07-01

## Business question
How do consumer-facing stocks react differently to company-specific events
(like a CEO change or earnings miss) compared to macro events (like the 2025 tariffs)?
